# Creator Growth Journal — starter website

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or double-click `index.html`.
4. Edit HTML files, `assets/css/style.css`, and `assets/js/script.js`.

## Pages
Home, About, Blog, Services, Contact, Privacy Policy, Affiliate Disclosure, and four sample articles.

## Before publishing
- Replace starter branding, biography, services and article content with original information.
- The contact form is a DEMO. It does not send emails; connect a secure form provider and update privacy information.
- Replace sample articles with fact-checked original content.
- Add real domain, canonical URLs, sitemap, robots.txt and analytics when you have a live domain.
- Check local laws and advertising/affiliate program requirements.
- The site uses Google Fonts via an external CDN; for an entirely offline site, use system fonts instead.

## Free deployment
Use GitHub Pages or Cloudflare Pages for this static HTML/CSS/JS website. No backend is required for the pages themselves.
